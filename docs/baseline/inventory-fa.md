# Existing ERP baseline: Inventory and Fixed Assets (source: modules/inventory; Fixed Assets live in modules/accounting)

## Sidebar as-is (Inventory)
Dashboard (customizable widget grid, mock series) | Product Management: Items, Item Category, Discounted Item | Configuration: Attributes, Location, Bins, UOM | Operations: Stock Transfer, Bin Transfer, Scrap, Inventory Adjustment | Sales, Purchase (empty placeholders) | Reports (16) | Settings: Inventory Settings (landed cost toggle), Forms, Template Editor.
## Sidebar as-is (Fixed Assets, inside Accounting)
Fixed Asset Management: Assets Management, Asset Transfer. Reports: Depreciation Schedule, Fixed Assets Register.

## Items
Types: Inventory, Non Inventory, Assembly (Finished product), Service, Package, Inventory Fixed Asset. List columns SKU, Name, Reorder Level, Status (Active/Inactive). Server-driven multi-tab form. Fields: profile image, type, sku, name, category, brand, UOMs, costing method, traceability (Lot Tracking / Serial Number Tracking / No Tracking), use bins, landed cost, prices, accounting accounts, reorder point, reordering rules, vendor information, rental fields (is_rental ...). View shows variants, location-wise stock, bin-wise stock, serial/lot stock, moves history. Adjust Stock button.
NOT existing: Product Classification (Inventory / Rental / AMC / Fuel Trading / Trading), Tracking Method Serialized/Quantity/Length, Sub-Category master with custom attributes per category, item photo displayed on record, mandatory asset value fields for serialized items.

## Item Category / Configuration
Item Category (Category Name, Parent, Status, Level, Sub Categories, attribute assignment). Attributes, Location (warehouse: Name, Address, Company, Status, parent location, inventory_available), Bins, UOM templates. NOT existing: Location Type Own Yard / Supplier-Held Location with Linked Supplier, Stock Held / Consumption / Remaining Value per location, custom attributes per category.

## Operations
Stock Transfer (statuses draft, ready, done), Bin Transfer, Scrap, Inventory Adjustment (only quantity-correction document, no workflow status). Serial/lot trace modal. NOT existing: Physical Stock Verification (count session, system qty snapshot, variance, Stock Adjustment linked to variance and approval). Only a "Stock Reconciliation" report.

## Fixed Assets (Accounting module)
- Assets Management list: ID, Asset Type, Asset Name, Asset Value, Depreciable Value, Net Asset Value, Depreciation Method, Status (running, cancelled, sell). Row actions View, Edit, Modify (Dispose), Delete.
- Form: series number, asset name, specification, asset type, asset value, net asset value, not depreciable value, book value, acquisition date, put to use date, location, department, company, depreciation (Straight line / Declining), declining factor, computation (Constant periods / Based on days per period), duration months, accounts (fixed asset, depreciation, expense), journal, insurance entries (amount, date, due date, account).
- View: cards (name, type, method, NAV, life, total depreciation), Depreciation Board table, Insurance table, Summary/Activity. Depreciation entries generated by backend; no run button.
- Modify/Dispose page: Dispose (date, loss account, description), Re-evaluate, Devaluate/sale (customer, amount, date of sale). No approval flow.
- Asset Transfer: asset, reference, original value, cumulative depreciation, transfer name/date, source/destination location, department, approval + quick approval.
- NOT existing: Unified Asset Status (Ready for Hire / On Hire / Off Hire / Breakdown / Under Maintenance / Disposed / Yard / Hold) on the register, Ownership Type (Owned / Cross-Hired / Spare-Standby), Cross-Hire Idle flag, Current Location derived from Movement History, Utilization %, Idle Time, Profitability on the asset record, Useful Life in hours, QR/barcode tag, Active/Inactive flag, Movement History, asset-level Compliance and Certificates (registration, insurance, inspection, warranty with reminder lead time), Manual Usage and Status Recording (HMR), Disposal Request with approval, Asset Category master, maintenance.

## Reports (existing)
Inventory: Inventory Valuation, Stock Status, Reorder, Stock Movement, Expiry Date, Stock Reconciliation, Slow Moving Inventory, Warehouse Stock Aging, Warehouse Transfers, Return to Vendor, Inventory Aging, Inventory Cost Analysis, Stock Movement Turnover, Stock On Hand, Stock Reservation, Schedule Report. Accounting: Depreciation Schedule (start/end date, company), Fixed Assets Register (Asset ID, Name, Category, Purchase Date, Cost, Depreciation Method, Accumulated Depreciation, NBV, Location, Department, Salvage Value, Useful Life; filters company, asset type, location, department, status).
NOT existing: Asset Utilization, Asset Profitability, End-of-Useful-Life, Category Demand vs Owned, Overdue/Missing Usage Readings, Idle Time, Movement History, Owned vs Cross-Hire vs Spare-Standby, Location-Wise Stock, Physical Stock Variance, Certificate Expiry, Asset Disposal / Write-Off reports; Fleet Status, Owned vs Cross-Hire, Asset Profitability, Location-Wise Stock, End-of-Life Planning dashboards.
